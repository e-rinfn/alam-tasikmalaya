# Virtual Tour Interaktif Objek Wisata Alam Tasikmalaya

## Deskripsi Project

Virtual Tour Interaktif Objek Wisata Alam Tasikmalaya merupakan sebuah aplikasi berbasis web yang dirancang untuk memberikan pengalaman eksplorasi wisata secara virtual menggunakan teknologi panorama 360 derajat. Pengguna dapat menjelajahi berbagai destinasi wisata alam di Tasikmalaya secara interaktif melalui tampilan panorama, navigasi lokasi, serta informasi wisata yang terintegrasi.

![Homepage](img\homepage.png)

Aplikasi ini memanfaatkan teknologi **Pannellum 360** untuk menampilkan panorama virtual tour, **Leaflet.js** sebagai sistem pemetaan interaktif, serta dikembangkan menggunakan bahasa pemrograman **PHP**, **JavaScript**, dan database **MySQL** sebagai media penyimpanan data.

![Virtual Tour](img\virtualtour.png)

Project ini bertujuan untuk membantu promosi wisata daerah, meningkatkan akses informasi wisata, serta memberikan pengalaman digital yang menarik bagi wisatawan.

---

## Fitur Utama

- Menampilkan panorama virtual tour 360 derajat
- Navigasi antar lokasi wisata secara interaktif
- Integrasi peta digital menggunakan Leaflet.js
- Informasi detail objek wisata
- Tampilan responsive untuk desktop dan mobile
- Sistem manajemen data wisata menggunakan MySQL
- Hotspot interaktif pada panorama virtual tour
